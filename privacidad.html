Política de privacidad de Hermes Jair

Última actualización: 3 de noviembre de 2026

1. Responsable

Hermes Jair es una aplicación de escritorio de uso estrictamente personal, operada por su único usuario (Jair Acevedo, jairesacevedo@gmail.com). No es un servicio ofrecido al público ni admite cuentas de terceros.

2. Datos a los que accede

Con autorización expresa del titular de la cuenta de Google, la aplicación accede a: correo de Gmail (lectura, envío y modificación), eventos de Google Calendar, archivos de Google Drive, documentos de Google Docs, hojas de cálculo de Google Sheets y contactos (solo lectura). No accede a contraseñas ni a datos de pago.

3. Finalidad

Los datos se usan únicamente para ejecutar las tareas que el usuario le pide a la aplicación desde su propio computador: leer y redactar correos, revisar y crear eventos, y consultar o editar archivos del propio usuario.

4. Almacenamiento y seguridad

El procesamiento es local. Los tokens de autorización se guardan en el disco del equipo del usuario y se pueden revocar en cualquier momento. No se envían datos a servidores del responsable porque no existen servidores del responsable.

5. Cesión a terceros

No se venden, alquilan, comparten ni ceden datos personales a terceros. No se usan para publicidad, perfilamiento comercial ni entrenamiento de modelos.

6. Uso limitado

El uso de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado.

7. Retención y eliminación

La aplicación no mantiene una base de datos propia. Las copias temporales necesarias para una tarea se eliminan al terminar. Al revocar el acceso o desinstalar la aplicación se borran los tokens almacenados.

8. Derechos del titular

El titular puede revocar el acceso en myaccount.google.com/permissions o escribir a jairesacevedo@gmail.com para solicitar información o eliminación de datos locales.

9. Cambios

Cualquier cambio en esta política se publicará en esta misma página con su fecha de actualización.
