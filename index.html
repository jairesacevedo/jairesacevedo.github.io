Hermes Jair

Aplicación de escritorio de uso personal — no es un servicio público.

Qué es

Hermes Jair es un agente de escritorio instalado en el computador de su único usuario (Jair Acevedo). Se conecta a las APIs de Google para que su dueño pueda consultar y organizar su propia información desde la terminal. No tiene registro de usuarios, no se distribuye y no presta servicio a terceros.

Qué datos de Google usa

  • Gmail (lectura, envío y modificación): leer el correo propio y enviar o responder mensajes a petición del usuario.
  • Google Calendar: consultar, crear y actualizar eventos del calendario propio.
  • Google Drive: leer y subir archivos del Drive propio.
  • Google Docs y Sheets: leer y editar documentos y hojas propias.
  • Contactos (solo lectura): resolver nombres y correos.

Cómo se tratan los datos

  • Todo el procesamiento ocurre en el computador del usuario. Los datos no se envían a servidores propios: no existen.
  • Los tokens de acceso se guardan cifrados en el disco local del usuario y se pueden revocar en cualquier momento.
  • No se venden, comparten ni ceden datos a terceros.
  • No se usan datos de Google para entrenar modelos ni para publicidad.
  • El uso que la aplicación hace de la información recibida de las APIs de Google cumple la Política de Datos de Usuario de los Servicios API de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso

En myaccount.google.com/permissions se puede retirar el permiso en cualquier momento; la aplicación deja de tener acceso de inmediato.
